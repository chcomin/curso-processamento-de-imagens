# Curso de Processamento Digital de Imagens

Curso de Processamento Digital de Imagens ministrado no Departamento de Computação UFSCar. 

O curso é dividio em módulos (M01, M02, ...). Cada módulo possui dois diretórios: teoria e prática. O diretório *teoria* em geral possui slides em pdf ministrados em aula. O diretório *prática* possui notebooks Jupyter numerados apresentando implementações dos conceitos.

## Principais tópicos abordados

1. Visão biológica e aquisição de imagens digitais;
2. Transformações pontuais de intensidade;
3. Filtragem espacial: suavização e derivada
4. Filtragme no domínio da frequência;
5. Pirâmides de imagens para o processamento multiescala;
6. Morfologia matemática;
7. Representação de descrição de imagens;
8. Análise de Componentes Principais;
9. Conceitos de Aprendizado de Máquina para imagens;
10. Conceitos de Redes Neurais Artificiais;
11. Classificação de imagens;
12. Detecção e segmentação de objetos.
