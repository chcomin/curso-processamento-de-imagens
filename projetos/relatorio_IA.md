
## Guia para Elaboração do Relatório de Uso de IA

**Objetivo:** Este documento deve acompanhar a entrega final do projeto de Processamento Digital de Imagens (PDI). O propósito é detalhar como ferramentas de Inteligência Artificial Generativa (ex: ChatGPT, Claude, GitHub Copilot, Gemini) auxiliaram no desenvolvimento do código e na compreensão dos conceitos teóricos.

Caso tais ferramentas não tenham sido utilizadas, indicar "não foram utilizadas ferramentas de IA".

### Estrutura do Documento

O relatório deve ser breve (1 a 3 páginas) e conter as seguintes seções:

#### 1. Ferramentas e Escopo
Liste quais ferramentas foram utilizadas e em quais etapas do projeto elas foram aplicadas.
* **Exemplos:** "Uso do GitHub Copilot para autocompletar funções de filtragem espacial"; "Uso do ChatGPT para depuração de erros de plotagem"; "Uso do Claude para explicar a fundamentação teórica da convolução".

#### 2. Registro de Prompts e Interações
Para as partes mais críticas do projeto (lógica de algoritmos ou resolução de bugs complexos), descreva a estratégia de interação.
* **Contextualização:** Como você explicou o problema para a IA?
* **Refinamento:** Você precisou corrigir a IA? Forneça exemplos.

#### 3. Descrição da Intervenção Humana
A implementação direta de código sugerido pela IA sem modificação é desencorajada. Nesta seção, indique:
* Quais trechos de código foram **escritos integralmente por você**.
* Quais trechos foram **gerados pela IA e modificados por você** (explique o que foi alterado para se adequar aos requisitos do projeto).
* Como as funções geradas se integram à arquitetura geral do sistema.

#### 4. Validação e Testes
Explique como você validou se o código gerado pela IA está processando as imagens corretamente de acordo com a teoria. Quais testes você usou para garantir que o resultado não era apenas visualmente aceitável, mas matematicamente preciso?
